01 / CRAWLINGOBSERVED

The site tells search robots not to read it.

WHAT WE FOUND

The public robots.txt file, which gives instructions to search crawlers, says ‘User-agent: *’ and ‘Disallow: /’. That tells compliant crawlers not to read the site.

WHY IT MATTERS

This can make it harder for search engines to discover or refresh information about restaurants and events. It does not mean Sky River is absent from Google.

THE PROOFLive crawl directive ↗View captured evidence ↗
HOW VESSEL WOULD FIX IT

Ask the website owner whether the instruction is intentional. If public crawling is wanted, approve the correct settings, check the sitemap and review which pages Google can access.

02 / PAGE STRUCTUREOBSERVED

The homepage needs clearer labels for assistive tools.

WHAT WE FOUND

We found no primary H1 heading, the code label usually used for the page’s main title. Several images also have generic or empty text alternatives; some may be decorative.

WHY IT MATTERS

People using a screen reader may have a harder time understanding the page structure or an important image. A visual review alone cannot tell which images need an explanation.

THE PROOFHomepage heading and image check ↗
HOW VESSEL WOULD FIX IT

Add a clear main page heading. Review each image, write helpful descriptions where they convey information, and keep decorative images silent. Check the result with keyboard and screen-reader navigation.

03 / SEARCH CONTEXTOBSERVED

Search tools could get clearer restaurant and event details.

WHAT WE FOUND

We found no JSON-LD block on the homepage. This is extra code that gives search tools a structured description of the business; the site already has useful restaurant and entertainment pages.

WHY IT MATTERS

Accurate, connected details can make it easier for search tools to understand which venue or event a page describes. Missing this code alone does not establish a ranking problem.

THE PROOFHomepage search-code check ↗
HOW VESSEL WOULD FIX IT

Review the priority venue and event pages, add eligible structured details where useful, and check names, times and locations against the public content. Then validate the code.

04 / THE FIRST CLICKOBSERVED

The first homepage action leads to slots, not dinner.

WHAT WE FOUND

The main homepage action goes to slots. Dining is available in the navigation and further down the page, with its own restaurant destinations.

WHY IT MATTERS

A person arriving from a food or entertainment ad may have to look again for the experience that caught their attention.

THE PROOFCurrent homepage order and hero destination ↗
HOW VESSEL WOULD FIX IT

Send hospitality campaigns to a matching restaurant or entertainment page. Pair it with a short food, people or place film and clear arrival or reservation details.

A few terms used in the checks: Google Business Profile is your listing in Maps and local search. SEO means making the business easier to find in search. A lab speed test simulates one phone visit; field data summarizes real visits. LCP measures when the main content appears, TBT measures delays before a page responds, and CLS measures content jumping around. JSON-LD is extra website code that describes the business to search tools. GTM (Google Tag Manager) manages website tracking tags. Core Web Vitals are Google’s checks for loading, responsiveness and visual stability. Origin data covers the whole website; URL data covers the tested page. INP measures how quickly the page responds after a tap or click. GA4 means Google Analytics 4, a tool for measuring website visits and actions.
